# منصة الصف الإلكتروني — مدرسة البلاد القديم

## محتويات المشروع
- `index.html`: واجهة الطلاب (العلوم والرياضيات، اختيار الصف والجزء والفصل، الدروس، حل النشاط، النتيجة من 10، دائرة إحصائية).
- `Code.gs`: واجهة Google Apps Script التي تقرأ الأنشطة وتصحح الإجابات وتحفظ المحاولات في Google Sheets.
- لا توجد لوحة إدارة داخل الموقع؛ إدارة المحتوى وفتح/قفل الأنشطة تتم من Google Sheet.

## 1) إعداد Google Sheets
1. أنشئ Google Sheet جديداً وانسخ معرّف الملف من الرابط بين `/d/` و`/edit`.
2. افتح Extensions > Apps Script والصق محتوى `Code.gs`.
3. استبدل `PASTE_GOOGLE_SHEET_ID_HERE` بمعرّف ملفك.
4. شغّل الدالة `setup` مرة واحدة ووافق على الصلاحيات.
5. ستُنشأ أوراق `Activities` و`Submissions` و`AnswerKeys`. ورقتا المحاولات ومفاتيح الإجابة مخفيتان.

## 2) إضافة الدروس والأنشطة
أضف صفاً في ورقة `Activities` لكل نشاط. الأعمدة:
`id | subject | grade | part | unit | title | description | open | questions_json | pdf_url`

القيم:
- `subject`: استخدم `science` أو `math`.
- `grade`: `السادس` أو `الأول الإعدادي` أو `الثاني الإعدادي` أو `الثالث الإعدادي`.
- `part`: `الجزء الأول` أو `الجزء الثاني`.
- `open`: اكتب `TRUE` لفتح النشاط و`FALSE` لإغلاقه.
- `questions_json`: أسئلة اختيار من متعدد بصيغة JSON، مثال:
```json
[
 {"text":"ما وحدة قياس القوة؟","choices":["النيوتن","المتر","اللتر"],"answer":"النيوتن"},
 {"text":"أي مما يلي عدد أولي؟","choices":["9","11","15"],"answer":"11"}
] Teams.
